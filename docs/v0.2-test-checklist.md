# v0.2 Player QoL 测试清单

## Bhop

- [ ] 默认关闭；`!bhop`可独立开关。
- [ ] 按住跳跃键可以连续跳跃，但没有速度 boost。
- [ ] 重连后恢复 Cookie，换玩家互不影响。
- [ ] Cookie 尚未缓存时使用默认值且不报错。
- [ ] `sm_l4dp_bhop_enabled 0`后不修改按键。

## Character

- [ ] Nick、Rochelle、Coach、Ellis、Bill、Zoey、Francis、Louis 均可选择。
- [ ] `m_survivorCharacter`和模型同步。
- [ ] 多名玩家可选择同一角色。
- [ ] spectator、死亡玩家和换图期间不能切换。
- [ ] 重连或换图后插件不恢复上次选择。
