# v0.3 AFK Manager 测试清单

## Auto Idle

- [ ] 插件加载时没有 translation parse、missing phrase 或格式参数错误。
- [ ] 英文和简体中文客户端均能正确显示 `{1:d}` 倒计时与 `{1:N}` 玩家名称。
- [ ] 110 秒显示 10 秒 HUD，119 秒仍未 Idle，120 秒执行 Idle。
- [ ] 移动、视角、跳跃、蹲下、攻击、推击、Use、物品切换、聊天和 Players 命令会取消警告。
- [ ] 小于 0.5° 的视角抖动不会无限重置。
- [ ] 被特感控制时保持等待，脱控且仍无活动后才 Idle。

## Kick

- [ ] 手动 Idle、自动 Idle和游戏原生 Take a Break 均开始 Idle 计时。
- [ ] 默认最后 60 秒只显示 HUD，不刷聊天。
- [ ] `!join`立即取消 Idle Kick。
- [ ] `z`管理员仍会 Auto Idle，但默认不被踢。
- [ ] Free Spectator 先经过 60 秒宽限，再独立计时并显示 HUD。
- [ ] timeout 为 0 时对应功能关闭；warning 大于 timeout 时被 clamp。

## 全员状态

- [ ] 配置 `sb_all_bot_game 1`和`allow_all_bot_survivor_team 1`后，所有真人 Idle 时战役继续。
- [ ] 任意真人执行 `!join`可以恢复。
- [ ] 所有真人最终被踢后，`sv_hibernate_when_empty 1`允许空服休眠并可重新唤醒。

## Human Team Wipe

- [ ] 保持 `sb_all_bot_game 1`并启用`sm_l4dp_human_team_wipe 1`。
- [ ] 1 真人 + 3 Bot：真人真正死亡后，剩余 Bot 被杀死并由游戏自然判定团灭。
- [ ] 1 真人进入 Engine Idle + 3 Bot：绑定 Idle Bot 活着时不团灭。
- [ ] 2 真人：一人死亡，另一人的 Idle Bot 活着时不团灭。
- [ ] 所有参与真人真正死亡、仅普通 Bot 存活时触发团灭日志并杀死 Bot。
- [ ] 真人只是倒地或挂边但仍存活时不触发团灭。
- [ ] Free Spectator 和从未加入本轮的玩家不进入参与者记录。
- [ ] `round_end`、换图、插件或该功能禁用时不执行 Bot 自杀。
