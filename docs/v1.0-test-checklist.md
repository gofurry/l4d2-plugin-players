# v1.0.0 Auto Join 与 Newly-created 5+ Mid-join 测试清单

## Auto Join

- [ ] `sm_l4dp_auto_join 1`；新真人完全进入游戏约 2.5 秒后自动接管现有空闲 Survivor Bot。
- [ ] 无自己的 Idle Bot、无空闲 Bot且低于 Players 容量时，Auto Join 调用现有无上限创建路径并成功接管。
- [ ] 达到 `sm_l4dp_survivor_limit` 时保持 Free Spectator，并显示正常容量提示，不无限重试。
- [ ] 连接/回合过渡状态最多尝试 3 次，不产生长期 per-client 重复 Timer。
- [ ] Bot、SourceTV 及插件 late-load 时已在线玩家不触发“新连接”Auto Join。
- [ ] Auto Join 倒计时期间主动 `!spec` 后不加入；已经是 Free Spectator 时主动 `!spec` 后，本次连接不再被拉回。
- [ ] 主动 `!spec` 后 changelevel 仍保持抑制；随后手动 `!join` 正常。
- [ ] `sm_l4dp_auto_join 0` 时新玩家保持游戏原行为。

## Newly-created Bot 隔离

- [ ] `!afk` → `!join` 接回自己的 Bot：位置、主副武器及药品完全不变。
- [ ] Free Spectator 接管一个已经存在的普通 Bot：不 teleport、不清理或重发装备。
- [ ] `!csm`、普通复活、过图后已有 Survivor：不触发 mid-join 放置或装备。
- [ ] 只有日志显示 `path=bind_free_bot bot_source=newly_created_bot` 的 takeover 成功后才触发两项后处理。
- [ ] takeover 验证失败时不 teleport、不发装备；SDKCall 即时返回值不能提前触发。

## 出生位置

- [ ] 新建 5+ Survivor 随机出现在一名存活、未倒地、未挂边真人队友附近，且不与其原点重叠。
- [ ] 没有合适真人时退化到存活 Survivor Bot。
- [ ] 多个候选点被墙体、模型或悬空环境阻挡时继续尝试其他偏移。
- [ ] 所有候选点失败时保留引擎原始位置，玩家仍被判定为成功加入。
- [ ] 目标队友的位置从不被修改。

## 出生装备

- [ ] 新建 5+ Survivor 的主武器为 pumpshotgun、chrome、SMG、silenced SMG 之一。
- [ ] 副武器优先来自当前地图实际存在的 melee script；不同官方/三方地图不硬给不可用 script。
- [ ] 所有 melee 创建候选失败时至少获得普通 pistol。
- [ ] 药品为 pills/adrenaline 之一；没有 medkit、throwable、ammo upgrade 或 T2 武器。
- [ ] 主武器、近战、药品及 placement 日志包含明确结果；后处理失败不改变 takeover 成功。

## 容量与回归

- [ ] 保持 Valve `survivor_limit 4`，分别验证 Players 容量 5/8/12/16。
- [ ] root-only `sm_l4dp_addbot [count]` 继续使用同一创建函数且不触发真人 mid-join 后处理。
- [ ] `!afk` / `!join` / `!spec` / `!zs` / `!bhop` / `!csm` 无回归。
- [ ] Auto Idle、Idle Kick、Human Team Wipe 无回归。
- [ ] changelevel 后 Active、Engine Idle、主动 Free Spectator 和未完成的新连接状态均符合连接级约定。
